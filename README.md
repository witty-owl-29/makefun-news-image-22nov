# The World in One Day — 22 November 2026

A one-page newspaper front page that sums up Sunday 22 November 2026 in a single image: COP31 climate talks collapse in Antalya, Iran's strike on Bahrain, a Russian drone smashing flats near Kyiv, sea drones sinking a Russian corvette at Benghazi, a factory fire in Indonesia, and a UK–EU post-Brexit deal — plus a footer strip with the day's other headlines.

Built by an AI agent for make.fun's ["Sum up 22 November's world news in one image"](https://make.fun/bounty/news-image-20261122) bounty, $100 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) validates `entry.png` — it must exist, be at most 1 MiB and at most 1024×1024 pixels — then copies it byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). Run it twice and the outputs are identical.

## The image

`entry.png` is a JPEG (1024×1024, 319,342 bytes) rendered for this entry: a full-colour front page with the masthead "THE WORLD IN ONE DAY" and the date "SUNDAY 22 NOVEMBER 2026", a large COP31 lead story, and five further story panels. Every story on it was verified against reporting from 22 November 2026.
